How sharing works (seed_data.json)

1) Hit Export to download your local seed_data.json (all 4 tables). 2) Commit that file to git. 3) Teammate pulls and hits Import (merge) or runs python scripts/seed_db.py. Schema changes: run alembic upgrade head first — see Help tab.

How to use

  • Backend: fastapi dev inside portal-end/backend. Tables auto-create on start (main.py:40).
  • API docs: /docs (CRUD at /api/reports|nodes|users|messages, stats at /api/stats, debug at /api/debug/*).
  • Data share: Keep portal.db gitignored. Commit seed_data.json instead. Export via button or python scripts/export_db.py, import via button or python scripts/seed_db.py (merge upserts, replace wipes first).
  • Schema changing a lot? We use Alembic. After editing models/*.py: alembic revision --autogenerate -m "describe" then alembic upgrade head. Teammates do git pull && alembic upgrade head && python scripts/seed_db.py (or scripts/setup.sh).
  • Polling: Nodes go offline after 15s without heartbeat (packets/packet_handler.py). Debug page polls every 5s when auto is on.
